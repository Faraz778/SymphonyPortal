# Symphony Limited - IT Training Institute Portal

A complete web application for an IT Training Institute including a public-facing website and a fully functional Admin Panel.

## Tech Stack
- ASP.NET Core MVC
- C#
- Entity Framework Core (Code First)
- SQL Server
- Bootstrap 5

## Features
- Public website showcasing courses, faculty, and contact info
- Admin Panel for managing Courses, Batches, Instructors, and Enrollments
- Code First EF Core with full migration support
- Fully responsive design
- 100% project document completion
